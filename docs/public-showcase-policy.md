# Public Showcase Policy

A project may be included when at least one of the following is true:

- Mohamed Radi owns the project and may publish it.
- The project owner has approved public showcase materials.
- Only public website screenshots and non-confidential engineering descriptions are used.

Never publish:
- private source code
- credentials or tokens
- customer data
- private analytics
- unreleased commercial strategy
- infrastructure details that materially weaken security

Every project entry should be labeled as one of:
`LIVE` • `DEMO` • `CONCEPT` • `PRIVATE / SHOWCASE ONLY`
